Live slate and odds

app/api/slate/route.ts asks ESPN's World Cup scoreboard for the current Eastern Time date and refreshes the browser every 60 seconds. The response is normalized into two team choices with American odds, implied probability, and profit on a $50 trade.

If the upstream source is unavailable, the route returns a clearly labeled verified schedule. The public booth never exposes developer controls.

AI portrait editing

app/api/generate/route.ts sends the normalized selfie through Vercel AI Gateway to a production image-edit model. Vercel supplies a short-lived OIDC identity to the Function, so no long-lived image key is placed in the browser or repository.

The server-owned prompt preserves the guest's identity while re-rendering the face, hair, neck, body, costume, background, light, and texture together. Every active country and school has a distinct treatment.

Pick-card art is preview-only. A finished slip can contain only a matching, newly generated square portrait—never a pasted face, pre-made body, or original-photo fallback.

The camera stays closed unless the exact image model has passed a sub-42-second release canary and the live Vercel billing probe succeeds.

Verification checklist

  1. Type-check and create a production Next.js build.
  2. Confirm the live slate endpoint returns the current match and source status.
  3. Exercise the public path at desktop and mobile sizes.
  4. Render the native 1080 by 1080 canvas and confirm the framed portrait and live values remain legible.
  5. Run real hosted edits for France, Belgium, Spain, and USC and load each matching result into the Gallery Slip.
  6. Check the repository for prohibited copy before deployment.
