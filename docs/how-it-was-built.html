The public experience

The booth keeps the interface deliberately small. A guest takes or uploads one photo, chooses one of the two teams in the current match, and receives three finished cards. The trade amount stays fixed at $50.

Live slate and odds

app/api/slate/route.ts asks ESPN's World Cup scoreboard for the current Eastern Time date and refreshes the browser every 60 seconds. The response is normalized into two team choices with American odds, implied probability, and profit on a $50 trade.

If the upstream source is unavailable, the route returns a clearly labeled, verified fallback so the booth remains testable. Developer mode exposes the source, location, draw price, every returned game, and all 48 tournament teams.

AI portrait editing

app/api/codex-image-job/route.ts creates a workspace-only handoff for Codex's built-in Image Gen. It writes the normalized input and exact team prompt to .codex/booth-image-job, then the page polls for the generated result. No API key is required for this local test.

The prompt preserves the guest's face, skin tone, body proportions, hair, expression, and camera angle. It changes only wardrobe, prop, and background styling. France uses an exaggerated football-emperor costume with comic medals and a tiny crown, while explicitly excluding real insignia and authoritarian symbols.

The browser cannot invoke Codex tools directly. The local handoff keeps that boundary honest while still making the real generated portrait available to the final square export.

app/api/generate/route.ts keeps OpenAI and Gemini as optional production providers. They are not required for the local Codex workflow.

Verification checklist

  1. Type-check and create a production Next.js build.
  2. Confirm the live slate endpoint returns the current match and source status.
  3. Exercise the public path at desktop and mobile sizes.
  4. Render the native 1080 by 1080 canvas and confirm the framed portrait and live values remain legible.
  5. Run a real built-in Image Gen edit and load the matching result into the Gallery Slip.
  6. Check the repository for prohibited copy before deployment.
